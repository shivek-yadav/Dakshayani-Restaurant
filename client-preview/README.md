# Client presentation preview

Open `index.html` in any modern browser. No installation or MongoDB is required.

This is a **standalone concept preview**, not the production React application. It demonstrates premium layout, responsive navigation, dish filters, search, a locally simulated cart and reservation request dialog. **It does not create orders, bookings or accounts.** For actual end-to-end workflows, run the full MERN application in `/client` + `/server` following the repository root README.

Images and Google Fonts load from external public URLs and require internet. Replace all sample imagery, reviews, address and brand content with client-approved assets before publication.
